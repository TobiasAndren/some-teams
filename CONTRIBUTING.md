# Contributing

Thanks for considering contributing to this project! 🎉

## How to contribute

1. Fork the repository
2. Create a new branch (`git checkout -b fix-card-heights`)
3. Make your changes in `header.php` (CSS) or `index.php` if needed
4. Commit and push your branch
5. Open a Pull Request and link it to the issue

## Notes

- Keep CSS changes in the `<style>` section inside `header.php`
- Please keep the layout responsive
